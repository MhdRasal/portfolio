# Muhammed Rasal — Portfolio

Personal portfolio for Muhammed Rasal, a full-stack AI product engineer building automations, local video generation, games and apps.

## Featured work

- **SocialAgent** — AI content workforce for planning, generating and publishing short-form video.
- **WanStudio** — full-stack AI video generation studio with Kaggle and Modal GPU backends.
- **Wan2GP Finetune** — custom WanGP build for finetunes, checkpoints and low-VRAM generation.
- **Lightning Control** — operations console for WanGP/Kaggle account pools, templates and jobs.
- **Nikah Invitation** — animated digital invitation with RSVP and admin dashboard.
- **Tiny Swords** — wave-survival arena game built with Godot 4 for web and Android.

## Stack

React 19, Vite, Tailwind CSS v4, Framer Motion, Lenis and the Parkinsans typeface.

## Development

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```
